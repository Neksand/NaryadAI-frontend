# Питч 3 минуты + Q&A

## Скрипт 0:00–3:00

0:00 — Смена: мастер видит аварии, сроки, загрузку.
0:20 — Выдача аварийного наряда за минуты: участок, оборудование, описание.
0:55 — Исполнитель: уведомление, принять, начать. Статус у мастера обновляется.
1:15 — Сдача: работы, шифр, материалы, фото «после». ИИ проверяет и объясняет.
1:50 — Дефектный пример: нет фото → needs_rework, мастер решает.
2:15 — Аналитика: рейтинг с формулой, тренды, повторные отказы, экспорт XLSX.
2:40 — Пилот: один участок, замеры до/после, стоимость.

## Q&A (9)

1. Где ИИ, где человек? ИИ советует (verdict/score/confidence), закрывает мастер.
2. Без API-ключей? Да — mock-профиль, локальные правила.
3. Повтор из офлайна? Idempotency-Key, один UUID на операцию, реплей без дублей.
4. Конфликт 409? Действие дропается из очереди, карточка обновляется, объяснение.
5. Просрочки? Дедлайны, напоминания, доска просроченных.
6. Рейтинг? Формула: качество, сроки, возвраты, объём, отклонения.
7. Фото свежесть? EXIF + client taken_at, лимиты 5 до / 10 после.
8. Роли? worker/master/manager/admin, скоупы на сервере, фронт только UX.
9. Внедрение? Пилот на участке, метрики до/после, обучение смены.

## Q&A дополнительно: зафиксированные чтением кода места конкурентов (10–12)

10. Backend G, порядок проверок при повторе действия. `src/routes/work-orders.ts:231–233`
возвращает наряд по совпавшему глобальному `clientActionId` раньше owner/role-проверок
`:235–237`. Дополнительно `:229` читает статус до транзакции, `:257` обновляет только по id.
Вывод статического чтения, атака не выполнялась. У нас: idempotency связана
с `(employee_id, key)` (`app/routers/work_orders.py`, `app/deps.py:149–222`), доступ
перепроверяется до возврата результата.
11. CRM, тесты. В `package.json` есть dev/build/lint, test-скрипта нет; поиск
`rg --files | rg '(test|spec)\.(js|jsx|ts|tsx)$'` тестовых файлов не нашёл. Внешняя
CI-проверка этим не исключается. У нас: backend 955 тестов, frontend 607 тестов,
см. индекс доказательств.
12. Mobile, адрес API. `lib/features/auth/data/auth_session.dart:125` — адрес API зашит
в исходнике; параметр окружения для URL в README назван нереализованным. Смена стенда
требует правки кода. У нас: адрес backend задаётся только переменными окружения
(`VITE_API_URL`, `VITE_WS_URL`), код при переезде не меняется.
