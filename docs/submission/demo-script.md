# Демо-скрипт на 7 минут (2 телефона)

Телефон А — мастер (`master1/3333`). Телефон Б — исполнитель (`worker01/1001`).
Запасной вход: `admin/1234`. Стенд: seeded dev, `VITE_API_URL=http://localhost:8080/api/v1`.

## 0:00–1:00 — Выдача (А)

1. А: вход `master1/3333` → панель смены (аварии, сроки, загрузка).
2. А: «+ Наряд» → участок, оборудование (можно по QR), описание, приоритет `critical`, исполнитель `worker01` (подсказка ИИ: топ-3 кандидата).
3. А: выдать. Показать наряд в статусе `issued`.

## 1:00–2:00 — Принятие и работа (Б → А)

4. Б: вход `worker01/1001` → уведомление о наряде (in-app + WS, без перезагрузки).
5. Б: открыть → «Принять» → «Начать» (`issued → accepted → in_progress`).
6. А: карточка наряда обновилась сама (WS-событие `WORK_ORDER_transition`, подсветка 2 с).

## 2:00–3:30 — Сдача с фото и проверка ИИ (Б → А)

7. Б: «Завершить» → форма: текст работ, шифр (подсказка ИИ по описанию), материалы, ≥1 фото «после» (unplanned без фото не сдаётся).
8. Б: отправить → статус `ai_review`, виден прогресс проверки.
9. А: открыть «Проверка ИИ» → verdict, score, confidence, checks (completeness/relevance/materials/timing/photos), объяснение.
10. А: «Согласен» (`review/decision: agree_ai`) → `closed`.

## 3:30–4:30 — Дефектный пример (Б → А)

11. Б: второй наряд сдать без фото «после» (или с завышенным расходом материала).
12. А: verdict `needs_rework`, наряд авто-перешёл в `rework`, замечания ИИ видны.
13. А: «Вернуть на доработку», Б видит причину. (Опционально: Б досдаёт фото → повторная проверка.)

## 4:30–5:30 — Аналитика и XLSX

14. Вход `manager1/2222` (или admin): дашборд смены, рейтинг исполнителей с формулой, повторные отказы, тренды.
15. «Экспорт» → XLSX (`POST /reports/export → 202 → signed_url`), показать скачанный файл.

## 5:30–6:00 — Офлайн (Б)

16. Б: выключить сеть → «Начать»/«Приостановить» уходит в очередь IndexedDB (бейдж).
17. Включить сеть → реплей по порядку тем же `Idempotency-Key`, без дублей.

## 6:00–7:00 — Пилот

18. Один участок, замеры до/после: время выдачи, реакция на аварию, часы простоя, повторные неисправности за 7 дней, полнота сдачи.
19. RU/KK-переключатель без потери сессии — показать одним тапом.

## Если что-то пошло не так

- WS не обновил: потянуть-обновить, пропуск `seq` сам инвалидирует экран.
- `409 invalid_transition`: кнопки рисуются только из `allowed_actions` — обновить карточку.
- `423 account_locked`: 5 неверных PIN — разблокировать через admin.
- Запасной план: резервная запись демо.
