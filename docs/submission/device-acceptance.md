# Device acceptance (бланк на 2 телефона)

1. Мастер входит, выдаёт аварийный наряд исполнителю.
2. Исполнитель видит уведомление, принимает, начинает.
3. Исполнитель сдаёт с фото «после», видит статус проверки.
4. Мастер открывает проверку ИИ, закрывает с оценкой.
5. Дефектная сдача (без фото) → needs_rework → доработка.
6. Офлайн: действие в очередь → reconnect → отправка без дубля.
7. Руководитель открывает аналитику и скачивает XLSX.
8. Переключение RU/KK без потери сессии.
9. Уведомления: прочтение одного и всех.
10. Обновление статуса без ручной перезагрузки (WS).
