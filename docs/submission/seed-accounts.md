# Сид и учётные записи (dev/test only, в проде seed заблокирован)

Генератор: `NaryadAI-FastAPI-Backend/scripts/seed.py` — идемпотентный (`ON CONFLICT DO NOTHING/UPDATE`),
повторный запуск дубликатов не создаёт. Объём: 4 участка, 25 единиц оборудования
(именные: Конвейер К-3, Дробилка КМД-1750, Насос ГрАТ-250), 3 бригады, 19 сотрудников,
20 шифров, 40 материалов, **600+ нарядов за 90 дней** + 3 свежих плановых с due +12–14 дней
(чтобы на демо всегда были активные работы) + 4 инсайта.

## Вход (только seeded dev!)

| Роль | Логин | ПИН |
| --- | --- | --- |
| Админ | `admin` | `1234` (из `SEED_ADMIN_PIN`; в проде `1234` запрещён) |
| Руководитель | `manager1` | `2222` |
| Мастер | `master1` / `master2` | `3333` / `4444` |
| Исполнитель | `worker01` … `worker15` | `1001` … `1015` |

На live-проде seed отключён — вход этими данными даёт `401 unauthorized` (ожидаемо).

## Запуск

```sh
docker compose up -d postgres redis s3
python -m scripts.migrate
python -m scripts.seed
```

## Паттерны для демо

1. Конвейер К-3 — повторные отказы подшипника М-02.
2. Дробилка КМД-1750 — внеплан после ППР.
3. Насос ГрАТ-250 — перерасход масла.
4. Бригада 3 и worker15 — медленные/низкие оценки (видно в рейтинге).
